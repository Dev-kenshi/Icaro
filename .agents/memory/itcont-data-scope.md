name: ITCONT public data scope
description: Agreed limits on information that may be stored from the ITCONT event source.
---

Use only event details and guests publicly listed on the Even3 event page. Keep publicly hosted image URLs as links; do not download or copy image files. Do not store attendee or registrant lists, payroll, private accounts, or operational records.

**Why:** The user explicitly limited the source and scope to public event information and named guests.

**How to apply:** For ITCONT database, API, or import work, retain only public page data and source-hosted image links. Do not infer other ITCONT datasets or access private records without a separately authorized source.
