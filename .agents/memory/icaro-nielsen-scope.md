---
name: Ícaro Nielsen review scope
description: Scope boundary for usability reviews of the Ícaro product.
---

Evaluate the complete user-facing Ícaro interface, including login, holographic stage, overview, analysis, copilot, and administrator screens. Do not treat the developer API as part of the Nielsen interface review unless the user explicitly expands the scope.

**Why:** The project owner clarified that “interface completa” means the product UI, not the API for developers.

**How to apply:** When auditing usability, inspect navigable user screens, interaction states, errors, and role-based paths. Keep API contracts and business behavior unchanged unless separately requested.
